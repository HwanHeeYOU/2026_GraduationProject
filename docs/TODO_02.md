## 바뀐 것

### 1. `.hwp` 업로드 → `.hwpx` 로 변환해 저장 → 내보낼 때 답변 채움
- `lib/hwp/hwpToHwpx.ts`: 문단·표(행/열/병합/폭)를 읽어 같은 구조의 HWPX 생성. 파란 글씨(작성 예시)는 파란색으로 보존
- `lib/hwp/hwpxText.ts`: 네이티브 `.hwpx` 도 같은 방식으로 문항 추출용 텍스트 생성 (표는 행 단위 `구분 | 내역 | …`, 파란 글씨는 `〔예시〕`)
- 버그 수정: `.hwp` 텍스트 추출이 표 안의 글을 전부 놓치던 문제

### 2. 문항 추출 (`app/api/ai/irb-form-draft/route.ts`)
- 여러 건 입력 표는 `표 이름 (열1 / 열2 …) - 여러 건 입력` 으로 추출. "칸을 추가하여 기재" 문구가 없어도 머리글 아래 같은 모양의 행이 이어지면 해당
- `〔예시〕` 는 문항이 아님, 행 번호 열·총계 줄은 열 목록에서 제외
- 자연어 입력을 앞 4000자에서 자르던 버그 수정 → 12,000자까지 전부, 넘으면 문항과 관련 있는 문단 우선 (`lib/irb/naturalInput.ts`)

### 3. 양식 채우기 (`lib/export/fillHwpx.ts`) — "문서 끝으로 가는 항목" 줄이기
- **열 표**: 한 줄 = 한 행, ` / ` 로 열 구분, 행이 모자라면 복제. 괄호 없는 `열1 / 열2 - 여러 건 입력` 도 인식. 한 표 안에 머리글이 여러 개여도 각각 채움
- **행 번호 열**(`1, 2, 3 …`)은 건드리지 않고, 행을 늘리면 번호를 이어 매김
- **머리글 없는 빈 칸 영역**(자격사항 등): 한 건당 한 칸씩
- **그룹 + 하위 라벨**(`공동연구자` 옆 `성 명 / 소 속 / 직 위`): `공동연구자 성명` 문항을 정확한 칸에. 2명 이상이면 묶음을 복제해 칸 추가 (양식의 "2인 이상인 경우 칸을 추가하여 작성")
- AI 가 여러 사람·여러 행을 ` | ` 로 이어 줘도 건 단위로 나눔 (예전엔 마지막 칸에 몰려 들어감)
- **체크박스**(`□ 교수 □ 박사과정 …`): 맞는 항목에 `☑`, 없으면 `☑ 기타(답변)`
- **하위 라벨**(`휴대전화 : / 연구실 :`): 전화번호·이메일은 값 종류로 짝지음
- **라벨 + 템플릿 줄**(`3. 연구기간 : IRB승인후부터 ~ 0000년 00월 00일`): 템플릿을 답으로 교체
- **제목 구역**(`4) 개인정보 보호 및 제공에 관한 사항` + 아래 안내문): 문항 단어가 그 구역에 다 있으면 제목 바로 아래에
- 파란 예시·자리표시 문구(`대학/대학원  학과/학부`)는 지우고 덮어씀, 덮어쓴 글자는 검은색

### 4. AI 지어내기 차단 (`lib/irb/grounding.ts`)
- 프롬프트: 입력에 없는 내용은 쓰지 않음이 최상위 규칙. 답마다 `[근거]` 로 입력 원문 인용
- 코드 검사 — 걸리면 그 답은 `[작성 필요]` (터미널에 `근거 없는 답변 차단 (사유): 문항`)
  - `number-not-in-input`: 입력에 없는 숫자 (사례비 금액, 대상자 수, 보관 기간, AI 가 더한 총계)
  - `evidence-not-in-input`: 입력에 없는 문장을 근거로 인용
  - `answer-not-in-input`: 답에 입력에 없는 문장이 섞임 (기준 0.7, 너무 많이 막히면 `CLAUSE_MIN_COVERAGE` 를 0.6 정도로)
- 주제 검사는 막지 않고 경고만 (`확인 권장 (off-topic, 답변은 유지)`) — 입력에서 나온 내용이지만 다른 칸의 것일 수 있음

## 알려진 한계

- `.hwp` 변환 시 글꼴·굵기·정렬·셀 색·그림·머리글/바닥글은 안 가져옴 (파란 글씨만 보존). 똑같은 모양이 필요하면 `.hwpx` 원본 업로드
- 별개 셀이 병합돼 보이는 경우가 있음 (친구 확인, 원인 미조사)
- 열 머리글이 두 줄이거나 가로 병합된 복잡한 표, 병합/그림이 든 행의 복제는 못 함 → 문서 끝으로
- 같은 머리글의 표가 여러 개면 엉뚱한 표에 들어갈 수 있음
- 번호가 `1, 2, 3` 이 아닌 번호 열(`가, 나, 다`)은 인식 못 함
- 공동연구자·연구원이 2명 이상이면 `성 명 / 소 속 / 직 위` 묶음을 복제해 칸을 늘림. 묶음 경계를 넘는 병합 칸이 있는 등 안전하게 복제할 수 없는 구조면 한 칸에 사람마다 한 줄로 넣음. 칸이 늘어나 표가 다음 쪽으로 넘어갈 수 있음
- 지어내기 차단 때문에 입력이 적으면 `[작성 필요]` 가 늘어남 (의도된 동작 — 검토 화면 "추가 정보 입력"으로 채움). 원문을 많이 바꿔 쓴 정상 답도 막힐 수 있음
- 입력 문장을 그대로 썼지만 칸과 미묘하게 어긋나는 답은 못 막음 → 검토 화면에서 확인
