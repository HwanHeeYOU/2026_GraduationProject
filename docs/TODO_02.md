## 알려진 한계 (고칠지 판단 필요)

- `.hwp` 에서 변환한 HWPX 는 **글꼴·색·굵기·정렬·그림·머리글/바닥글을 가져오지 않음** (글 내용·표 구조·병합·폭만 유지). 원본과 똑같은 모양이 필요하면 `.hwpx` 원본을 올려야 함
- 열 머리글이 두 줄이거나 가로로 병합된 복잡한 표는 열 분리를 못 찾아 기존 방식(문서 끝 모음)으로 감
- 행 복제는 병합/표/그림이 든 행에서는 못 함 → 못 넣은 줄은 문서 끝에 모임
- 문항에 열 이름이 `( / / )` 로 안 들어 있으면 열 분리 불가
- 체크박스/선택형 칸(☐/☑)은 처리하지 못함
- `[작성 필요]` 항목은 일부러 비워 둠 (HWPX 에서 비는 박스의 정상적인 원인 중 하나)
